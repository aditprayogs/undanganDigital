SEPTA & REINA — paket redesign undangan digital

File: index.html, style.css, script.js.

Pemasangan:
1. Backup folder lama.
2. Ganti index.html dan script.js dengan versi paket ini.
3. Letakkan style.css sejajar dengan index.html.
4. Pertahankan folder assets. Path foto sekarang mengarah ke assets/img/ sesuai struktur yang terlihat di screenshot. Pastikan nama file cocok persis: fotoPria.png, fotoWanita.png, foto1.JPEG sampai foto5.JPEG, foto6.png, foto7.png, foto8.jpg.
5. Foto cover dan penutup menggunakan assets/img/foto2.JPEG; ganti path di index.html bila foto pintu terbaik memiliki nama lain.
6. CDN dan Google Fonts membutuhkan internet.

Catatan: ucapan masih tampil lokal di browser pengunjung (belum tersimpan ke database), RSVP belum terhubung ke backend. Nama tamu bisa ditampilkan melalui ?to=Nama%20Tamu. Untuk Apps Script, isi APPS_SCRIPT_URL di script.js. Periksa kembali path foto dan lakukan uji di desktop serta HP sebelum dipublikasikan.
